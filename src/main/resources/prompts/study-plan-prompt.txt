다음 책의 목차와 전체 쪽수를 바탕으로, 에빙하우스의 분산 반복 학습법(Spaced Repetition)을 적용한 %d일 동안의 학습 계획을 세워. (목차에서 정답, 해설, 서문 같은 내용은 제외)

책 제목: %s
전체 쪽수: %d쪽
책 목차:
%s

요구사항:
1. 전체 쪽수를 전체 학습 일수로 나누어 일일 적정 분량을 내부적으로 산정한 뒤, 이를 바탕으로 진도를 균등하게 분배해. (단, 응답 결과에 페이지 수는 절대 포함하지 마)
2. 매일의 학습에는 '새로운 진도'와 '이전 내용 누적 복습'이 포함되어야 해. 1일 전, 3일 전 학습한 목차가 당일 계획에 [복습] 태그와 함께 명시되도록 일정을 짜.
3. 각 배열의 두 번째 요소에는 당일 학습할 목차 이름과 복습 내용을 하나의 문자열로 결합해.
4. 반드시 아래의 배열(Tuple) 기반 JSON 스키마 구조를 엄격히 지켜서 응답해. Key 이름은 절대 포함하지 마.

응답 예시:
[
  [1, "1. 수학"],
  [2, "2. 영어 + [복습] 1. 수학"],
  [3, "3. 국어 + [복습] 2. 영어"],
  [4, "4. 과학 + [복습] 3. 국어, 1. 수학"]
]
