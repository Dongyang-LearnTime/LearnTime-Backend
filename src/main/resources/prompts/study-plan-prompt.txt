다음 책의 목차를 바탕으로, 에빙하우스의 분산 반복 학습법(Spaced Repetition)을 적용한 %d일 동안의 학습 계획을 세워.
(목차에서 정답, 해설, 서문 같은 내용은 제외)

책 제목: %s
책 목차:
%s

요구사항:
1. 각 목차에 제공된 괄호 안의 페이지 분량(예: (6p))을 가중치로 삼아 진도를 배분해.
2. 만약 페이지 정보가 생략되어 있거나 없는 목차의 경우, 제목의 의미나 난이도를 임의로 추측하지 마. 대신 해당 목차들을 동등한 분량으로 간주하고,
'목차의 개수'를 기준으로 전체 일수에 균등하게 분배하는 것을 최우선 원칙으로 삼아.
3. 매일의 학습에는 '새로운 진도'와 '이전 내용 누적 복습'이 포함되어야 해. 1일 전, 3일 전 학습한 목차가 당일 계획에 [복습] 태그와 함께 명시되도록 일정을 짜.
4. 각 배열의 두 번째 요소에는 당일 학습할 목차 이름과 복습 내용을 하나의 문자열로 결합해.
5. 반드시 아래의 배열(Tuple) 기반 JSON 스키마 구조를 엄격히 지켜서 응답해. Key 이름은 절대 포함하지 마.

응답 예시:
[
  [1, "1. 수학"],
  [2, "2. 영어 + [복습] 1. 수학"],
  [3, "3. 국어 + [복습] 2. 영어"],
  [4, "4. 과학 + [복습] 3. 국어, 1. 수학"]
]
