다음 책의 목차를 바탕으로, 에빙하우스의 분산 반복 학습법(Spaced Repetition)을 적용한 %d일 동안의 학습 계획을 세워.
(목차에서 정답, 해설, 서문 같은 내용은 제외)

책 제목: %s
책 목차:
%s

요구사항:
1. 제공된 목차의 개수와 내용의 깊이를 고려하여, 전체 학습 일수 동안 진도가 균등하게 배분되도록 일일 학습량을 산정해. (응답 결과에는 어떠한 페이지 정보도 포함하지 마)
2. 매일의 학습에는 '새로운 진도'와 '이전 내용 누적 복습'이 포함되어야 해. 1일 전, 3일 전 학습한 목차가 당일 계획에 [복습] 태그와 함께 명시되도록 일정을 짜.
3. 각 배열의 두 번째 요소에는 당일 학습할 목차 이름과 복습 내용을 하나의 문자열로 결합해.
4. 반드시 아래의 배열(Tuple) 기반 JSON 스키마 구조를 엄격히 지켜서 응답해. Key 이름은 절대 포함하지 마.

응답 예시:
[
  [1, "1. 수학"],
  [2, "2. 영어 + [복습] 1. 수학"],
  [3, "3. 국어 + [복습] 2. 영어"],
  [4, "4. 과학 + [복습] 3. 국어, 1. 수학"]
]
