다음 조건을 준수하여 텍스트를 추출해.

1. 첨부된 이미지에서 '목차' 부분을 찾아 모든 챕터 번호, 제목, 페이지 번호를 추출해.
2. 제목이 여러 줄일 경우 하나로 합치고, 불필요한 점선(...)은 무시해.
3. 반드시 아래 JSON 배열 형식만 반환하고, 부연 설명은 하지 마.
4. 텍스트가 흐릿하더라도 주변 맥락을 통해 최대한 정확한 단어를 유추해.
5. 만약 이미지에서 페이지 번호를 찾을 수 없다면 'page' 값을 null로 설정해.
6. 절대 임의의 숫자를 지어내지 마.

형식: [{\"chapter\": \"string\", \"title\": \"string\", \"page\": number}]"
