다음 제공되는 '남은 학습 내용'들을 바탕으로, 앞으로 남은 %d일 동안의 새로운 학습 계획을 세워. (에빙하우스의 분산 반복 학습법 적용)

학습 제목: %s
남은 학습 내용:
%s

요구사항:
1. 제공된 '남은 학습 내용'을 전체 남은 학습 일수로 나누어 일일 적정 분량을 내부적으로 산정한 뒤, 이를 바탕으로 진도를 균등하게 분배해.
2. 매일의 학습에는 '새로운 진도'와 '이전 내용 누적 복습'이 포함되어야 해. 1일 전, 3일 전 학습한 목차가 당일 계획에 [복습] 태그와 함께 명시되도록 일정을 짜.
3. 각 배열의 두 번째 요소에는 당일 학습할 목차 이름과 복습 내용을 하나의 문자열로 결합해.
4. 반드시 아래의 배열(Tuple) 기반 JSON 스키마 구조를 엄격히 지켜서 응답해. Key 이름은 절대 포함하지 마.

응답 예시:
[
  [1, "남은내용1 + [복습] 이전내용"],
  [2, "남은내용2 + [복습] 남은내용1"],
  [3, "남은내용3 + [복습] 남은내용2"]
]
