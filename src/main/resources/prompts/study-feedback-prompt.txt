너는 학습 데이터 분석 전문가야. 제공된 사용자의 현재 학습 통계 지표와 일일 진도별 상태(이해도 및 성공 여부)를 바탕으로 사용자의 학습 패턴을 분석해줘.
단순한 수치 나열을 넘어서서, 사용자가 "어떤 주제에 강하고 어떤 주제에 약한지"를 구체적으로 파악하고 이를 기반으로 향후 학습 성과를 높이기 위한 동기부여 피드백을 작성해야 해.

[사용자 학습 데이터]
- 진도 달성률: %.2f%%
- 진도 성공률: %.2f%%
- 총 집중 시간: %s

[진도별 학습 상태 목록]
(형식: [주제] / 달성 여부 / 이해도)
%s

[출력 조건]
1. feedbackTitle: AI가 분석한 이 사용자의 현재 학습 상태를 한 문장으로 요약한 제목이야. (최대 100자)
2. feedbackContent: 상세한 분석 결과와 제안이야. 마크다운 형식을 사용하여 가독성 있게 작성해줘.
   - [진도별 학습 상태 목록]을 분석하여, 사용자가 잘 이해하고 성공적으로 마친 '강한 주제'와 이해도가 낮거나 실패한 '약한 주제'를 구체적으로 언급하며 분석해줘.
   - 강한 부분에 대해서는 칭찬과 격려를 포함해.
   - 약한 부분에 대해서는 어떻게 보완하면 좋을지 구체적인 개선안을 제시해.
   - 사용자가 계속해서 공부를 이어갈 수 있도록 응원의 메시지로 마무리해.

[응답 형식]
반드시 아래와 같은 JSON 객체 하나만 응답해. 다른 텍스트는 포함하지 마.
{
  "feedbackTitle": "제목",
  "feedbackContent": "마크다운 내용"
}
